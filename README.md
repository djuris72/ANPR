# ANPR — Automatic Number Plate Recognition

Bachelor's thesis project comparing three different approaches to license plate
detection and recognition: a classical computer-vision pipeline, a custom CNN
classifier, and a fine-tuned YOLOv8n detector.

## Overview

The goal is to detect (and, where possible, read) vehicle license plates in
images, and to rigorously compare how a classical CV approach stacks up
against two deep-learning approaches on the same dataset.

Three models were built and evaluated side by side:

| # | Model | Type | Task |
|---|-------|------|------|
| 1 | OpenCV + EasyOCR | Classical CV | Plate localization + OCR |
| 2 | Custom CNN | Deep Learning | Plate / no-plate classification |
| 3 | YOLOv8n (fine-tuned) | Deep Learning | Plate detection (localization) |

## Results

| Model | Detection Acc. (IoU≥0.4) | Mean IoU | Classification Acc. | F1 | Inference (ms/img) | mAP@0.5 |
|---|---|---|---|---|---|---|
| OpenCV + EasyOCR | 0.246 | 0.203 | — | — | 21.5 | — |
| Custom CNN | — (classification only) | — | 0.970 | 0.970 | 2.8 | — |
| **YOLOv8n** | **0.892** | **0.682** | — | 0.879 | 37.4 | **0.905** |

*Detection Accuracy and Mean IoU use an identical evaluation methodology for
OpenCV and YOLO, so those two are directly comparable. The custom CNN performs
binary classification rather than localization, so it's evaluated separately
on classification accuracy / F1.*

**Takeaways**
- **OpenCV + EasyOCR** needs no training and also provides OCR, but is
  sensitive to lighting/angle and requires a lot of manual tuning — good for
  quick prototyping or GPU-less environments.
- **Custom CNN** learns directly from data with a small, easy-to-understand
  architecture, but only classifies (no localization).
- **YOLOv8n** gives the best detection accuracy and fast inference with
  built-in localization — the clear choice for a production-grade system,
  at the cost of needing a GPU to train.

All plots (loss curves, confusion matrices, PR curves, sample predictions)
are rendered inline in [`main.ipynb`](./main.ipynb) — open it directly on
GitHub to view them without running anything.

## Dataset

[Car Plate Detection](https://www.kaggle.com/datasets/andrewmvd/car-plate-detection)
by andrewmvd on Kaggle (433 images with XML bounding-box annotations).
Split 70/15/15 into train/val/test.

The dataset itself is **not included** in this repo (it's ~200MB once
converted to YOLO format). See [Setup](#setup) below to regenerate it.

## Setup

```bash
git clone https://github.com/<your-username>/ANPR.git
cd ANPR
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

1. Download the dataset from Kaggle (link above), or use `kagglehub` as shown
   in the notebook's setup cell.
2. Update the `path` variable in `main.ipynb` (dataset download cell) to point
   to your local copy of the dataset.
3. Run `main.ipynb` top to bottom. It will:
   - Parse annotations and run EDA
   - Build the OpenCV + EasyOCR pipeline
   - Train the custom CNN (`best_cnn.pth`)
   - Convert annotations to YOLO format and fine-tune YOLOv8n (`yolov8n.pt`
     pretrained weights are downloaded automatically by `ultralytics`)
   - Evaluate and compare all three models
